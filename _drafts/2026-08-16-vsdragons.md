# 11対0で中日に快勝

8月16日、バンテリンドームでの中日戦は11対0でジャイアンツが勝利！！
先発の小笠原慎之介が7回無失点

8回には打線が爆発して、止まらぬ止まらぬ一挙10得点！
完全に昨日の11失点をやり返した試合になった！！

# 先制点の意味

打線も1回から浦田俊輔の出塁と盗塁で作ったチャンスを、中山礼都がきっちり先制点につなげました
この試合は最終的に大差がついたけれど、やはり1回に先制できたのが大きかったと思う
何せ毎試合苦戦してる柳相手だからね…

浦田が塁に出て、走って、三塁まで進む。そこで中山がバスターを成功させて1点。
派手な長打ではなくても、先に点を取るために必要なことをきちんとやった攻撃だった。

中山のプレーについては、橋上監督代行も試合の大きなポイントだったと評価していた。こういう1点を取り切れると、見ている側も試合に入りやすい。

# 小笠原が7回無失点

小笠原は7回を投げて被安打3、8奪三振、無失点で3勝目

3回には無死満塁のピンチがあったが、石川昂弥を遊ゴロに打ち取って切り抜けた。
ここを無失点で終えたことで、試合の流れを中日に渡さなかったのが本当に大きい。
マジでエース格まで上がった！！最高ですわ！！！

[【巨人】小笠原慎之介、古巣本拠で７回０封「目の前のアウトをひとつずつ取るだけだと」ブーイングにも負けず３勝目…一問一答](https://hochi.news/articles/20260816-OHT1T51280.html)

# 8回の10得点

[【巨人】橋上監督代行「あそこは大きなポイントになった」中山礼都のバスターを称賛　打線組み替えも言及](https://hochi.news/articles/20260816-OHT1T51299.html?page=1)
[巨人・橋上監督代行、中山のバスター成功は「試合の大きなポイント」](https://www.sanspo.com/article/20260816-ERSUVP2KA5KDXO6S35SZJUTMAY/?outputType=theme_giants)


7回までは1対0だったので、正直いつひっくり返されてもおかしくない緊張感はあった。

しかし8回、打線が一気につながった。
ダルベックの犠牲フライ、大城卓三の2点二塁打、松本剛の適時打、丸佳浩の適時打、そして笹原操希の走者一掃となる二塁打。

終わってみればこの回だけで10得点。こういうイニングを見せられると、野球はやっぱり面白い
笹原の一打は特に痛快だった

# 北浦のナイスキャッチ

{% include twitter.html url="https://x.com/sanspo_giants/status/2088930132820185494?s=20" %}

8回からは、この日に昇格した北浦竜次が登板
2回を無失点に抑え、最後はピッチャーライナーを反射的に捕って試合終了！！

昇格直後の登板で、しかも最後を自分の守備で締める
2回しっかりと抑える、これをしっかり勤め上げたのは大きいよ？
開幕当初はなかなかだったけど、2軍でしっかり成長をしてきた証だね。

# 次の試合へ

でも、それ以上に先制点の取り方、小笠原の粘り、終盤に一気に畳みかけた打線と、それぞれに見どころがあった試合だった。
