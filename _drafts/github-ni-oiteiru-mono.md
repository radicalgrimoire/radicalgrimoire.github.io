# GitHubに置いているものと、いま続けていること

GitHubを見返すと、自分が何に時間を使っているかがわりとそのまま出ている。派手なアプリケーションよりも、開発を継続するための環境と手順が多い。

## Perforce / Helix Core

P4Vを使い始めるところから、サーバーの構築、コミット/エッジ構成、障害時の判断、復旧までをドキュメントとして残している。運用は一度だけ正しくできれば終わりではなく、困ったときに誰でも同じ判断へ戻れることが大事だと思う。

## Dockerと開発環境

Docker化したHelix Coreとプロキシ、WSL2上のDocker Engine、Unreal Horde Serverなども扱っている。環境構築は地味だが、個人の手順に閉じず、次に触る人が再現できる形にするほど価値が出る。

## 書くことも運用の一部

技術調査、構築手順、障害対応の記録は、忘れないためだけのメモではない。次の作業を速くし、確認の負担を減らし、チームで判断を共有するための道具でもある。AIを使った文章作成についても、使いどころを探りながら記録している。

## このブログでは

GitHubに置く手順書とは別に、野球観戦や作品の感想、日常で引っかかったことも書いていく。技術だけでは説明しきれない、何に興味を持って何を続けているのかを残す場所として、このブログを使いたい。
