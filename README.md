# radicalgrimoire

This is a personal blog about game-development technology, baseball games I attend, and the movies, anime, games, and events that catch my attention.

## What I Do

I work on the systems that keep development moving: Perforce / Helix Core operations, Docker-based development environments, WSL2, and Unreal Horde. I turn what I learn through research and incident response into procedures that can be used again.

## What I Write

- Development environments, version control, and infrastructure operations
- Baseball game reports
- Thoughts on anime, movies, and games
- Things that happen in everyday life

My technical documentation and public repositories are collected on [GitHub](https://github.com/radicalgrimoire).
