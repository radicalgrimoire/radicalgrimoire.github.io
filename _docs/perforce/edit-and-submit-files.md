# Pending ChangeListのタブを開く

{% include image.html src="/assets/docs/perforce/edit-and-submit-files/01_edit-and-submit-01.png" alt="Pending Changelist タブ" %}

編集中のファイルは、このタブに表示される

# ファイルを追加する

{% include image.html src="/assets/docs/perforce/edit-and-submit-files/01_edit-and-submit-02.png" alt="Mark for Add の操作" %}

追加したいファイルを選択して、Mark for Addを選択する

# ファイルを編集する

{% include image.html src="/assets/docs/perforce/edit-and-submit-files/01_edit-and-submit-03.png" alt="Check Out の操作" %}

既にサーバーにサブミットされているファイルを編集するには、
編集したいファイルを選択して、右クリックを押し、CheckOutを選択する。

これで編集ができる状態になる。

# ファイルを削除する

{% include image.html src="/assets/docs/perforce/edit-and-submit-files/01_edit-and-submit-04.png" alt="Mark for Delete の操作" %}

削除したいファイルを選択してMark for Deleteを選択する
