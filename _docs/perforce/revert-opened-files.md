# 編集中のファイルを元に戻したい

主に編集中のファイルを元に戻したい場合は、主にRevertを使って元に戻します

# 編集中のチェンジリストを選択　→　Revert Files を押す

{% include image.html src="/assets/docs/perforce/revert-opened-files/01_Revert01.png" alt="Revert Files の操作" %}

戻したいファイルを選択して元に戻す
